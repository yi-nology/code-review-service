# Internal planning & diagnostic documents

This directory holds **internal-only** artifacts: historical planning docs,
roadmaps, implementation summaries, and diagnostic reports produced during
development iterations.

These are **not user-facing documentation**. New users and operators should
consult the top-level [docs/](../) folder instead:

- [`docs/API.md`](../API.md) — HTTP API reference
- [`docs/CODE_REVIEW_POLICY.md`](../CODE_REVIEW_POLICY.md) — review/severity policy
- [`docs/OCR_CORE_DESIGN.md`](../OCR_CORE_DESIGN.md) — OCR engine integration design
- [`docs/PERFORMANCE.md`](../PERFORMANCE.md) — performance notes
- [`docs/webhook-writeback-design.md`](../webhook-writeback-design.md) — webhook & writeback design

Files here are kept for traceability of past decisions; they may be outdated
relative to the current codebase.
