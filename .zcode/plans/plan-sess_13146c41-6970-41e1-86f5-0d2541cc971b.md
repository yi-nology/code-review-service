## ReviewDetail 页面重新设计 — 左右双栏布局

### 问题
1. **通知中心不显示**：NotificationCenter 在 AppLayout 顶部栏渲染了，但 Bell 按钮在 0 未读时太不显眼。需增大按钮可见性。
2. **ReviewDetail 页面需重新设计为左右双栏**：当前是 16:8 两栏纵向堆叠，信息层级混乱（findings 被埋在 5 张卡片下面）。

### 设计方案：左侧固定信息栏 + 右侧 findings 滚动区

```
┌──────────┬────────────────────────────┐
│ 左栏(sticky) │ 右栏(滚动)                │
│            │                          │
│ 门禁结果卡  │ 摘要区(repo/status/操作)   │
│  PASS/FAIL │                          │
│  原因解释   │ ── Findings 列表 ──       │
│            │ · Finding 1 [critical]    │
│ 评分环      │   path:line  [误报][反馈]  │
│  85 / 100  │   描述...                 │
│  Grade B   │   现有代码 / 建议代码      │
│            │ ──────────────            │
│ 严重度分布  │ · Finding 2 [major]      │
│  严重 2    │   ...                     │
│  高危 5    │                          │
│  中危 8    │ ── 分析概览 ──            │
│  提示 3    │  根因/风险/建议            │
│            │                          │
│ ────────  │ ── OCR 执行信息(折叠) ──  │
│ 元信息     │  tokens/文件数/耗时        │
│  PR#123   │                          │
│  author   │ ── 发布面板 ──            │
│  SHAs     │                          │
│            │                          │
│ 操作按钮    │                          │
│  取消/重跑  │                          │
│  发布      │                          │
│            │                          │
│ ────────  │                          │
│ 历史/会话   │                          │
└──────────┴────────────────────────────┘
```

### 改动文件

#### 1. `frontend/src/components/layout/NotificationCenter.vue` — 修复可见性
- 0 未读时也显示 Bell 图标（当前 badge hidden 但按钮应在）
- 增大按钮尺寸/添加微妙背景，让用户能注意到

#### 2. `frontend/src/views/ReviewDetail.vue` — 完整重写模板 + 样式

**模板结构改为：**
- `<header>` 保留（返回 + repo 标题 + 操作按钮）
- 失败 alert 保留
- ProgressTracker 保留（running 时）
- `<div class="review-layout">` 替代当前 `<el-row>`，CSS Grid 双栏：
  - **左栏 `.review-sidebar`（sticky）**：
    - 合并 ReviewGateCard + 质量评估卡为一张「结果总览卡」：门禁状态 + 评分环 + 严重度分布 + 门禁解释 + 优先修复列表
    - 元信息紧凑展示（PR/MR、author、SHA、时间）
    - 操作按钮（取消/重跑/刷新）
    - 历史/会话入口（折叠）
  - **右栏 `.review-content`（正常滚动）**：
    - 摘要文本（detail.summary）
    - ReviewFindingsPanel（核心，最大面积）
    - 分析概览
    - OCR 执行信息（可折叠 `<el-collapse>`，默认折叠，降低噪音）
    - PublishPanel
    - ReviewDebugPanel

**脚本变更：**
- 删除 `summary-strip` 相关 computed（`getSummaryClass`/`getSummaryLabel`）——合并到左栏卡片
- 删除 `<el-row>/<el-col>` 相关
- 保留所有数据获取/轮询/viewer 逻辑不变

**样式变更：**
- `.review-layout { display: grid; grid-template-columns: 300px 1fr; gap: 20px; }`
- `.review-sidebar { position: sticky; top: 76px; max-height: calc(100vh - 90px); overflow-y: auto; }`
- 响应式：`<1024px` 时变为单栏（sidebar 在上，content 在下）

#### 3. 不新增子组件
- 左栏「结果总览卡」直接内联在 ReviewDetail 模板里（复用现有 ReviewGateCard 的逻辑思路，但合并评分环和严重度到同一张卡，减少卡片碎片化）
- ReviewGateCard 组件保留但不再在右栏重复使用（其逻辑内联到左栏总览卡）

### 不改的部分
- 所有 `<script>` 数据获取逻辑（fetchDetail/fetchSessions/polling/viewer）
- ReviewFindingsPanel / PublishPanel / ReviewDebugPanel 子组件
- API 调用
- OCR display 计算逻辑（buildOCRDisplay 等）

### 验证
- `npm run build` 通过
- 浏览器打开 `/reviews/:id` 确认双栏布局
- 通知中心铃铛可见
